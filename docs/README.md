# Mục lục Tài liệu Dự án Renmei

| Phiên bản : 0.1 | Ngày : 31-10-2026 | Trạng thái : Draft | Cổng | Người duyệt : Nguyễn Tấn Mạnh |

## 1. Cấu trúc tài liệu
- **`00-plan/`**: Kế hoạch tổng thể, ảnh baseline MS Project, Notion Board.
- **`01-requirements/srs.md`**: Yêu cầu phần mềm.
- **`02-design/`**: Thiết kế phần mềm (`sdd.md`), sơ đồ ERD (`erd.mermaid`), OpenAPI specs và ADRs.
- **`03-testing/`**: Kế hoạch kiểm thử (`test-plan.md`), test cases và báo cáo kiểm thử.
- **`04-deployment/`**: Hướng dẫn vận hành (`runbook.md`) và Release Notes.
- **`05-maintenance/`**: Quản lý thay đổi (`cr-log.md`) và theo dõi lỗi (`bug-log.md`).
- **`gates/`**: Biên bản nghiệm thu qua các cổng G1 - G5.
- **`rtm.md`**: Ma trận truy vết yêu cầu.
## 2. Quy ước Đặt mã truy vết
- **FR-xxx**: Functional Requirement, ví dụ: `FR-001`.
- **NFR-xxx**: Non-Functional Requirement, ví dụ: `NFR-001`.
- **CR-xxx**: Change Request, ví dụ: `CR-001`.
- **TC-xxx**: MTest Case ID, ví dụ: `TC-001`.
- **ADR-xxx**: Architectural Decision Record, ví dụ: `ADR-001`.
